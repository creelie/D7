# D7: earlier home of the BLLM paper

The BLLM paper and its engine now live in one repository,
[creelie/eBLLM](https://github.com/creelie/eBLLM):

- the paper *BLLM: Beyond the LLM with Deep Human-Mind-AI* by Deep Bhattacharjee and Ushashi
  Bhattacharya, with its source, Lean development and checks, is in
  [`paper/bllm`](https://github.com/creelie/eBLLM/tree/main/paper/bllm), and its compiled PDF in
  [`preprintBLLM`](https://github.com/creelie/eBLLM/tree/main/preprintBLLM);
- the engine Anaxia (command `anaxia`, container image `ghcr.io/creelie/bllm-engine`) is the rest of
  that repository, released and archived at Zenodo with the paper.

This repository keeps the earlier versions: the folder [`BLLM`](BLLM) and the PDF in
[`preprintBeyondTheLLM`](preprintBeyondTheLLM) are the paper as released here, v1.0.0
(https://doi.org/10.5281/zenodo.23449605) to v2.0.1 (https://doi.org/10.5281/zenodo.23456196), all
versions https://doi.org/10.5281/zenodo.23449604. New versions are released from eBLLM.
